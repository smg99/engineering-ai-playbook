# Client confidentiality

**This GitHub playbook is internal guidance only.** Real issues and acceptance criteria remain in the client's Jira; code, PRs and CI evidence remain in the client's Bitbucket. No automatic data sync into this repo.

Never include customer names, ticket URLs, source, screenshots, private logs, credentials, API keys, production records, architecture secrets or proprietary decisions in prompts hosted here. Only submit sensitive details to AI tools if the client and organization explicitly approve that provider and its data handling.

Store temporary execution plans and STATE notes only in policy-approved client or local locations. Sanitize examples. Keep repo private. **Do not enable public GitHub Pages**—source repo privacy does not automatically guarantee the published site is private. For now clone the repo and open `index.html` locally, or use authenticated internal hosting after security review.
